# web 形态：发现 + 诊断（不含启停）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `o824` 能发现、诊断 `dsh web` 形态（`npm i -g @deepseek-ai/dsh` 的全局包），并把两个形态的**版本漂移**（F11）报出来。**不含**启动/停止——那是 P2（§12）。

**Architecture:** 一个"安装"从只有 desktop 扩展成按**形状**分派：目录里有 `package.json` 且 `name == "@deepseek-ai/dsh"` 就是 web，否则走现有的 desktop 三件套。发现多一层：npm 全局前缀（`npm prefix -g`）与 pnpm 全局根。诊断多一条 F11：把**所有形态**的版本摆在一起，不一致就报。

**Tech Stack:** Rust；读 `node_modules/@deepseek-ai/dsh/package.json`；不调用 npm（我们自己算前缀，规则与 npm 文档一致）。

**Spec:** `docs/design/2026-10-28-dsh-launcher-design.md` §21.1（三形态）、§21.2（适配器操作）、§21.3（web 的特异性）、§21.4（共存：版本漂移）、§18.2（F11）、§12（P1 不含 start/stop）

## Global Constraints

- MSRV **1.89**；`cargo fmt --all --check`、`cargo clippy --all-targets -- -D warnings` 干净。
- desktop 的行为**逐字节不变**：八棵 fixture 的 golden 一个字符都不许动。
- 不新增 Rust 依赖；不调用任何外部命令（npm/pnpm）——前缀按 npm 的规则自己拼。
- web 的 `kind == "web"`，`installMethod == "npm"`；`root` 是**包目录**不是前缀。
- 真机（本机）实测：全局包 `0.2.1-rc.5`，desktop asar `0.2.1-rc.3` → F11 必须在这台机器上报出来。
